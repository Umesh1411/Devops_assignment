# Contributing to Simple Interest Calculator

Thank you for considering contributing to this project! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

### Bug Reports

If you find a bug, please open an issue on the GitHub repository with the following details:

- A clear and descriptive title.
- Steps to reproduce the issue.
- Expected behavior vs. actual behavior.
- Your environment details (operating system, Bash version, etc.).

### Bug Fixes

If you have identified a bug and know how to fix it:

1. Fork the repository.
2. Create a new branch for your fix.
3. Make the necessary changes.
4. Test your fix thoroughly.
5. Submit a pull request with a clear description of the problem and the fix.

### Documentation Improvements

Good documentation helps everyone. You can contribute by:

- Fixing typos or grammatical errors.
- Improving clarity or adding examples.
- Updating outdated information.

### Enhancements

If you have an idea to improve the existing functionality:

1. Open an issue describing the enhancement.
2. Discuss the proposed changes with the maintainers.
3. Once approved, implement the changes and submit a pull request.

### Ideas and Feature Suggestions

We welcome new ideas! To suggest a feature:

- Open an issue with the label **"feature request"**.
- Describe the feature and explain why it would be useful.
- Provide examples or references if possible.

## Pull Requests

When submitting a pull request, please ensure the following:

1. Your code follows the existing style and conventions of the project.
2. You have tested your changes locally.
3. Your commit messages are clear and descriptive.
4. The pull request description explains what changes were made and why.

## Contribution Guidelines

- Be respectful and constructive in all interactions.
- Follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).
- Keep changes focused — one pull request per issue or feature.
- Write clear commit messages.
- Ensure your changes do not break existing functionality.

Thank you for helping improve this project!
